# Prathamesh Portfolio

Static portfolio site published with GitHub Pages.

## Deploy

Push commits to `main` to publish the site. The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the repository contents to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The planned published URL is <https://Prathamesh13-dev.github.io/portfolio-site/>.
